# ImageScanner

## Описание
ImageScanner — это десктопное приложение на Qt C++ (Widgets), предназначенное для сканирования папки с графическими файлами и отображения основной информации об изображениях в виде таблицы. Приложение обрабатывает до 100 000 файлов в одной папке, работает многопоточно и не блокирует интерфейс во время сканирования.
Поддерживаемые форматы: JPEG (jpg, jpeg), PNG, BMP, GIF, TIFF (tif, tiff), PCX.
Все метаданные читаются вручную — побайтовым разбором заголовков по спецификациям форматов. Сторонние библиотеки для получения метаданных не используются. Единственное исключение — QPixmap, применяемый только для рендеринга превью в интерфейсе.

## Требования:
Qt 5.15 или Qt 6.x с модулем Widgets.
Компилятор с поддержкой C++17: GCC, Clang, MSVC или MinGW.
qmake (входит в состав Qt).
Операционная система: Windows, Linux или macOS.

## Сборка
Откройте терминал в папке с исходниками. Сгенерируйте Makefile, соберите проект. На Windows с MinGW используйте mingw32-make. С MSVC используйте nmake или jom.
Альтернативный способ: откройте ImageScanner.pro в Qt Creator и нажмите Build — Run.
После успешной сборки исполняемый файл ImageScanner (или ImageScanner.exe в Windows) появится в папке сборки.

## Запуск
Запустите ImageScanner или откройте проект в Qt Creator и нажмите Run.

## Использование
Нажмите кнопку Select Folder. В открывшемся диалоге выберите папку с изображениями. Диалог поддерживает навигацию по файловой системе. После выбора папки приложение начнёт сканирование. Все графические файлы с поддерживаемыми расширениями будут обработаны автоматически. Не-графические файлы игнорируются.
Во время сканирования прогресс-бар показывает текущий прогресс, а рядом отображается счётчик обработанных файлов.
По мере обработки строки появляются в таблице. Каждая строка содержит имя файла, формат, размер в пикселях, DPI, глубину цвета, тип сжатия и статус.
Щёлкните на любую строку — справа появится превью изображения.
Наведите курсор на строку со статусом Corrupted или Unsupported — появится всплывающая подсказка с описанием ошибки.
Чтобы отсортировать таблицу по нужному столбцу, щёлкните по заголовку столбца.
Чтобы отфильтровать строки, введите текст в поле Filter над таблицей. Фильтр ищет совпадение по всем столбцам одновременно, регистр букв не важен. Например, введите Corrupted, чтобы увидеть только повреждённые файлы, или введите png, чтобы увидеть только PNG.
Кнопка Clear очищает таблицу и превью, не удаляя файлы с диска. После завершения сканирования в верхней части окна отображается итоговое время работы.

## Обработка ошибок
Статус файла может принимать четыре значения:
OK — файл успешно разобран, все поля заполнены.
Corrupted — файл повреждён: пустой, слишком маленький, с отсутствующими обязательными чанками или маркерами, с нулевыми или абсурдными размерами.
Unsupported — формат не распознан по Magic Numbers. Например, текстовый файл с расширением jpg.
Error — файл не удалось открыть, например из-за отсутствия прав.
Точная причина ошибки отображается во всплывающей подсказке при наведении на строку.
