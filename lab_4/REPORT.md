# Лабораторная работа 4 — Базовые растровые алгоритмы

## Описание

Приложение для иллюстрации работы базовых растровых алгоритмов (отрезки, окружность, эллипс, дуга) на виртуальном растре. Позволяет строить примитивы пошаговым алгоритмом, ЦДА, Брезенхемом, Ву и Кастлом–Питвеем, просматривать пошаговый протокол вычислений, а также проводить стресс-тестирование производительности с построением графиков. Отрисовка сетки и пикселей выполняется отдельно от алгоритмов — через двумерный числовой массив яркостей.

## Функциональные возможности

### Семь алгоритмов растеризации

1. Пошаговый алгоритм (отрезок)
2. ЦДА (отрезок)
3. Брезенхем (отрезок)
4. Ву — сглаженный отрезок с честным расчётом прозрачности
5. Кастл–Питвей (отрезок, целочисленный, через алгоритм Евклида)
6. Брезенхем (окружность, 8 октантов через симметрию)
7. Питвей (эллипс и дуга, коническое сечение)

### Виртуальный растр и интерфейс

- **Виртуальный растр (`VirtualGrid`)** — массив яркостей `float`, начало координат в центре
- **Привязка целых координат к сетке:** (x; y) — центр клетки, клетка занимает [x−0,5; x+0,5] × [y−0,5; y+0,5]
- **Масштабирование сетки** (3–80 px на клетку, Ctrl + колесо)
- **Система координат:** линии сетки идут по полуцелым значениям, красные оси проходят через центры клеток x = 0 и y = 0, ось y направлена вверх
- **Подписи** координат и яркости сглаженных пикселей на крупном масштабе
- **Выбор примитива мышью:** ЛКМ — начало/центр, ПКМ — конец/радиус/полуоси
- **Пошаговый протокол** вычислений для любого примитива

### Стресс-тестирование (Benchmark)

Выполняется в отдельном потоке:

- «веер» из 100 000 отрезков во всех 8 октантах
- 50 000 окружностей и эллипсов разного радиуса
- 4 графика зависимости времени от числа примитивов и их размера
- замер высокоточным таймером (`QElapsedTimer`), берётся лучший результат из нескольких повторов
- сохранение графиков (PNG), CSV и сводки

## Установка и запуск

### Требования

- Windows 7/8/10/11
- Qt 5.15 или Qt 6.x
- qmake (входит в состав Qt)

### Запуск готового приложения

1. Распаковать архив
2. Запустить `lab4_raster.exe`

### Сборка из исходников

Собирать нужно в режиме **Release**: в Debug время искажается.

```bash
qmake lab4.pro
make
./lab4_raster
```

Или открыть `lab4.pro` в Qt Creator и собрать комплектом Release.

## Использование

1. Выберите алгоритм в выпадающем списке
2. Задайте координаты и параметры фигуры полями ввода или мышью по сетке (ЛКМ — начало/центр, ПКМ — конец/радиус)
3. Нажмите «Построить» — справа появится пошаговый протокол вычислений
4. Масштабируйте сетку (Ctrl + колесо или счётчик «Размер клетки»)
5. Наведите мышь на клетку — в строке состояния появятся её границы и яркость
6. Для бенчмарка перейдите на вкладку «Бенчмарк», задайте число примитивов и повторов, нажмите «Запустить»
7. По завершении сохраните результаты кнопкой «Сохранить графики и CSV...»

## Архитектура

| Слой | Модуль | Назначение |
|------|--------|------------|
| Model | `RasterEngine` | Чистые алгоритмы растеризации, знают только `IRasterTarget::setPixel(x, y, intensity)` |
| Model | `VirtualGrid` | Виртуальный растр — массив `float`, реализует `IRasterTarget`, при наложении оставляет максимальную яркость |
| Model | `Benchmark` | Стресс-тест в отдельном потоке, замеры `QElapsedTimer` |
| View | `GridPainter` | Рисует увеличенные клетки, сетку, оси и подписи по данным `VirtualGrid`; ничего не вычисляет |
| View | `ChartWidget` | Простой линейный график с несколькими сериями |
| View | `MainWindow` | Пользовательский интерфейс, вкладки «Растеризация» и «Бенчмарк» |
| Controller | сигналы/слоты `MainWindow` | Связь интерфейса с алгоритмами и бенчмарком |

Функции рисования примитивов (`drawLine`, `drawEllipse` и т. п.) не используются. `QPainter` применяется только в `GridPainter` для клеток и сетки и в `ChartWidget` для графиков.
