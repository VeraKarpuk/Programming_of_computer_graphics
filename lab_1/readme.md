# Color Converter - RGB ↔ XYZ ↔ HSV

## Описание

Приложение для интерактивной работы с цветом в трёх моделях: RGB, XYZ и HSV. 
Позволяет задавать цвет тремя способами (ползунки, поля ввода, палитра) 
с автоматическим пересчётом всех моделей при изменении любой координаты.

## Функциональные возможности

- Три цветовые модели: RGB (0-255), XYZ (0-100), HSV (H: 0-360°, S: 0-100%, V: 0-100%)
- Три способа задания цвета: ползунки, поля ввода, палитра
- Стандарты освещения: D65 (sRGB), D50 (полиграфия), E (равноэнергетический)
- Стратегии выхода за границы: Clipping (обрезание), Scaling (масштабирование)
- Динамические градиенты на ползунках
- Автоматический пересчёт всех моделей
- Предупреждения при выходе цвета за границы

## Установка и запуск

Требования:
- Windows 7/8/10/11
- Qt 5.15 или Qt 6.x
- CMake 3.16+

Запуск готового приложения:
1. Распаковать архив
2. Запустить ColorConverter.exe

Сборка из исходников:

mkdir build && cd build
cmake ..
cmake --build . --config Release
./ColorConverter

## Использование

1. Изменяйте цвет через ползунки, поля ввода или кнопку "Выбрать цвет из палитры"
2. Наблюдайте автоматический пересчёт во всех моделях
3. Меняйте стандарт освещения (D65/D50/E) для пересчёта матриц
4. Выбирайте стратегию обработки некорректных цветов (Clipping/Scaling)

## Архитектура (MVC)

Слой Model - ColorModel - Математика перевода цветов
Слой View - MainWindow - Пользовательский интерфейс
Слой Controller - ColorController - Связь интерфейса и математики
